# Typography

Quick reference for Framer text styles.

## Font families

| Use | Font | Source |
|---|---|---|
| Display & all headings | **Newsreader** | Google Fonts |
| Body & UI text | **IBM Plex Sans** | Google Fonts |
| Small labels (uppercase) | **IBM Plex Sans** | Google Fonts |

## Type scale

| Role | Font | Size |
|---|---|---|
| Display / H1 | Newsreader | 68px |
| H2 | Newsreader | 42px |
| H3 | Newsreader | 28px |
| Body | IBM Plex Sans | 18px |
| Small / Labels | IBM Plex Sans | 14px |
| Uppercase labels | IBM Plex Sans | 14px (tracked) |

## Pairing rules

- **Newsreader** is the editorial voice — use it for everything readers should slow down for
- **IBM Plex Sans** is the working voice — use it for everything readers should scan
- **IBM Plex Sans** is the signal — uppercase labels, section numbers, captions

## Don't

- Don't use Newsreader for body copy (it gets exhausting at 18px)
- Don't use IBM Plex Sans for headings above H4
- Don't introduce a fourth font
