# Assets

Visual files. Drag from here directly into Framer.

## Folder rules

| Folder | Purpose | Recommended format |
|---|---|---|
| `logos/` | Company logos for the trust carousel | SVG (preferred) or transparent PNG |
| `portrait/` | Hero portrait | High-res JPG, 2400×3000px minimum |
| `case-study-heroes/` | One hero image per case study | JPG, 1600×900 minimum, optimized |
| `icons/` | UI icons (LinkedIn, etc.) | SVG |

## Naming convention

- Lowercase, hyphenated: `new-playbook.jpg`, not `New Playbook.jpg`
- Match the case study slug exactly
- No spaces. No underscores. No camelCase.
