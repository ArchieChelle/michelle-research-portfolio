challenge:
  - Integration requests competed for limited engineering capacity without a defensible ranking framework.
  - Request volume biased decisions toward familiar tools rather than measured user value.
approach:
  - Designed a MaxDiff study to force trade-offs across integration options.
  - Added familiarity and satisfaction measures to interpret low-ranked tools and awareness gaps.
findings:
  - Scheduling and communication workflows ranked highest for the screened segment.
  - Spreadsheet integrations led at 39.5% preference share, far ahead of the next options.
  - Zapier ranked low while awareness was only 27.6%, indicating an education gap.
dataAnalysis:
  - "MaxDiff preference shares: Spreadsheets 39.5%, Mailchimp 12.6%, GameChanger 12.5%, Constant Contact 10.6%, TeamGenius 9.7%, Zapier 4.0%."
  - "Segment boundary: findings are strongest for active web users with CSV-upload workflows."
impact:
  - Graph API integration moved to production.
  - MaxDiff became a repeatable prioritization standard for integration decisions.
